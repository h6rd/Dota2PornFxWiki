# Как загрузить свой мод

## Требования к моду
Чтобы ваш мод был опубликован на сайте, он должен соответствовать следующим требованиям

### 1. Авторство
**Вы должны быть автором мода.**

Вы можете использовать часть чужого мода только с разрешения его автора - потребуется подтверждение (скриншот переписки, комментарий и т.п.).
- Вы считаетесь автором, если создали большую часть мода, а создатель меньшей части указывается как моддер (и наоборот). **При условии, что сам автор с этим согласен**

::: tip Мод с dota2skinchanger
Если мод берётся с dota2skinchanger, будет указан оригинальный автор, а вы - как моддер.
:::

### 2. Название
Название мода должно быть на английском языке.
Если мод предназначен для героя (модели, звуки, эффекты) — название должно содержать имя героя.

### 3. Превью
Мод должен иметь превью-изображение. Если превью нет — будет использована заглушка.

| Тип мода | Требование к превью |
| :--- | :--- |
| Мод на героя | Скриншот из игры без элементов UI (как на сайте) |
| Мод на звук | Видео, демонстрирующее изменение (желательно) |

### 4. Чистота файлов
Мод не должен содержать мусорных или не скомпилированных файлов.

::: warning Не принимается
Моды, содержащие файл `items_game.txt`, не принимаются.
:::

### 5. Работоспособность
Мод должен быть рабочим и не иметь сильных багов.

- Если предмет простой - он должен включать визуальные эффекты на модели (читайте в разделе гайдов).
- Если предмет или сет меняет иконки и эффекты способностей - они тоже должны быть включены в мод и работать корректно.

Модерация рассматривает каждый мод индивидуально и вправе отклонить его с указанием причины.
---

## Подготовка мода: скрипт PreMod
Для удобства сборки рекомендую использовать скрипт **[PreMod](https://github.com/h6rd/PreMod/releases)**.

::: tip Как пользоваться
1. В файле `config.json` укажите свой ник в кавычках `""`.  
2. Положите картинку мода и `.vpk`-файл рядом со скриптом.
3. Запустите скрипт - он попросит ввести название мода.
4. На выходе получится готовый `.zip`-архив.
:::

Готовый `.zip` нужно отправить мне.

::: tip При первой отправке
Укажите свой ник и ссылку, которая будет отображаться на сайте.
:::
